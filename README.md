## Подключение Bootstrap

В проекте Bootstrap подключён **локально**, без CDN. Файлы фреймворка размещены в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css` — стили;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JavaScript для интерактивных компонентов (navbar, dropdown, modal, accordion, carousel, tabs, toast). Bundle уже содержит библиотеку Popper для выпадающих меню.

Собственный `css/custom.css` подключается **после** Bootstrap, чтобы при необходимости переопределять его стили.

## Bootstrap-сетка

- `container` — ограничивает ширину и центрирует контент на всех страницах.
- `row` + `col-*` — 12-колоночная сетка.
- Адаптивные колонки:
  - карточки товаров: `col-12 col-md-6 col-lg-4` — 1 колонка на телефоне, 2 на планшете, 3 на компьютере;
  - hero и страница товара: `col-12 col-lg-6`;
  - преимущества: `col-12 col-md-4`;
  - поля формы заявки: `col-12 col-md-6`.
- Отступы между колонками — `g-3` и `g-4`.

## Реализованные компоненты

- `navbar` — с кнопкой мобильного меню, активным пунктом и выпадающим меню категорий (`dropdown`); закреплён сверху (`sticky-top`);
- `card` — карточки товаров, контейнер формы, карточки на странице контактов;
- `btn` — варианты `btn-primary`, `btn-outline-primary`, `btn-secondary`, `btn-light`, отключённая кнопка у проданного товара;
- `badge` — «Хит», «Новинка», «−10%», «Продано», счётчики товаров в категориях;
- `alert` — подсказки в каталоге, на странице товара и в форме;
- `modal` — быстрая заявка из любой карточки;
- формы — `form-control`, `form-select`, `input-group` (префикс «+7», суффикс «шт.»), `form-check`;
- `breadcrumb` — хлебные крошки;
- `table` — `table-striped table-bordered` внутри `table-responsive`;
- `accordion` — условия покупки;
- `carousel` — слайдер фото на главной;
- `nav-tabs` — вкладки на странице товара;
- `nav-pills` — быстрые переходы по категориям каталога;
- `toast` — уведомление об отправленной заявке;
- `list-group` — список контактов.

## Самостоятельные доработки

- **Локальное подключение Bootstrap** без CDN — файлы в `vendor/bootstrap/`.
- **Собственный контент:** 12 своих фотографий из поездки вместо «Товар 1–3», разбитые на 4 категории с якорями `#pets`, `#food`, `#cars`, `#places`.
- **Дополнительная страница** `contacts.html`.
- **Дополнительные компоненты:** `carousel`, `nav-tabs`, `nav-pills`, `toast`, `list-group`, `dropdown` с категориями.
- **Окно заказа знает товар:** при открытии из карточки `js/main.js` через событие Bootstrap `show.bs.modal` показывает «Вы заказываете: …» и сам выбирает фото в списке.
- **Bootstrap-валидация форм:** подсказки `invalid-feedback` под каждым полем, проверка формата телефона через `pattern`; после успешной отправки форма очищается и появляется `toast`.
- **Варианты карточек:** скидка (зачёркнутая старая цена, красная рамка), «Продано» (отключённая кнопка, приглушённая карточка), «Подробнее» у товара со своей страницей.
- **Страница товара:** вкладки с таблицей и accordion, блок «Похожие фото».
- **Аккуратный custom.css:** одинаковая высота фото в карточках (`object-fit: cover`), подъём карточки при наведении с учётом `prefers-reduced-motion`, пиксельный шрифт логотипа, отступ для якорей под закреплённым меню (`scroll-padding-top`).
- **Адаптивность** проверена на 375, 768, 1024 и 1280 px: нет горизонтальной прокрутки, меню сворачивается, сетки перестраиваются.
- **Публикация** через GitHub Pages.

## Как проверить

1. Открыть `index.html` — пролистать карусель, нажать «Заказать» у Porsche: в окне появится «Вы заказываете: Porsche 911 Gulf».
2. Нажать «Отправить» с пустыми полями — под полями появятся подсказки; заполнить и отправить — окно закроется и появится уведомление.
3. Открыть `catalog.html` — проверить переходы по категориям и выпадающее меню «Категории».
4. Открыть `product.html` — переключить вкладки, раскрыть accordion.
5. Открыть `order.html` — проверить валидацию (телефон в формате `900 123-45-67`).
6. В DevTools включить мобильный режим — меню сворачивается в кнопку, карточки встают в одну колонку.
